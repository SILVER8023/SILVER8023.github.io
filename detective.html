No.001失踪的维护者

案情

维护者“老K”失踪了。

他独自维护着一个 Claude Code 技能包仓库 oldk/midnight-skills。最后一次提交停在今天凌晨 03:12，只有一行：fix: typo。

当晚，他的仓库 star 暴涨。可人没留一句话——没有新 issue、没有告别帖、没有 fork 声明，就这么从开源世界里消失了。

他是被大厂招安了？受不了热度跑路了？还是换了个马甲，继续在别处维护？

真相

复盘

线索一 → 排除“跑路”：风口正盛——一个做技能包的人，在技能包最热的一夜，没有跑路的理由。单日 +706⭐ 断层登顶，17 个上榜项目过半是技能包，热度正处顶峰。

线索二 → 烟雾弹：指向“被大厂招安”，看似最合理的解释。但 SkillEvaluator 评的是技能本身的质量（质量门、语义重叠、live 评估），不招人；它评估的是已公开的技能仓库，不是挖维护者。大厂下场做裁判，不等于大厂把选手带走了。

线索三 → 指向真相：换马甲继续维护——人可以消失，技能进了注册表就还在流通。1,900 多个组件收进一个目录、一键安装，老K的技能不需要他本人出面，就能换个名字继续分发。

线索四 → 佐证真相：代码可以没有名字地流通——fork 的人要的是技能，不是老K这个名字；也可能是有人趁他消失，顺手拿走了代码。35 分钟后新建账号 fork 并压掉全部提交记录，人名被抹干净，代码仍在。
