冷宫探访登记簿

每天去看一个没人看的东西，留一句“今天有人来过”。

玩法：每天探访一件“无人认领”的东西，轮换四个冷宫——GitHub 0 星仓库、视频站 0 播放视频、论坛 0 回复帖子、歌单 / 播客 0 收藏作品。只看公开内容，不打扰作者本人；能留言的留一句“今天有人来过”，不能留言的只登记、不留痕。不点赞、不安利、不拉人围观——探访不是拯救。每周日把本周七张卡整理成一期；攒满一季，再查有没有“复活”（多了第一颗星、第一条回复）。为什么被冷落是猜测的，猜测会注明是猜测，不编造。
